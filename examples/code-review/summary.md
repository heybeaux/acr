# code-review

Comprehensive codebase audit framework. Analyzes source code for dead code, security vulnerabilities, dependency issues, architecture problems, code quality metrics, and test coverage gaps. Produces a prioritized report with severity ratings (Critical/High/Medium/Low) and actionable recommendations.

**Provides:** code-review, code-audit, technical-debt-analysis
**Requires:** exec (shell commands for running analysis tools)
**Triggers:** "code review", "code audit", "technical debt", "dead code", "security audit"

Six-phase process: Discovery → Dead Code → Dependencies → Code Quality → Architecture → Test Coverage → Report.
