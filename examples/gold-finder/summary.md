# Gold Finder — Transcript Opportunity Mining

Analyze meeting transcripts → identify AI/automation opportunities → produce client-ready report.

## Categories
1. **Process Automation** — repetitive tasks, manual workflows, data entry
2. **Intelligence & Insights** — reporting, analytics, pattern detection
3. **Customer Experience** — support, personalization, response time
4. **Content & Communication** — drafting, translation, summarization
5. **Decision Support** — forecasting, risk assessment, recommendations
6. **Revenue Enablement** — lead scoring, pricing optimization, upselling

## Output Format
Each opportunity: Name → Current Pain → AI/Automation Solution → Impact (1-5) → Effort (1-5) → ROI Priority

Quick wins (high impact, low effort) flagged first. Executive summary + detailed breakdown.
